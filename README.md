# Portfolio Website

A clean, responsive, and accessible personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript to showcase my projects, technical skills, and background as a Computer Science and Engineering student.

## Features

- **Light/Dark Mode Toggle:** Custom theme switcher with persistent user preference stored in `localStorage`.
- **Responsive Mobile Navigation:** Mobile-friendly hamburger menu with smooth toggle states and accessibility attributes.
- **Dynamic Skills Section:** Automatically renders a categorized list of programming languages, frameworks, and developer tools using modern JavaScript.
- **Interactive Project Filtering:** Filter portfolio projects by category with real-time matching counts and accessibility updates.
- **Client-Side Form Validation & Submission:** Robust contact form featuring input validation, error handling, focus management, and seamless AJAX submission via FormSubmit.

## Technologies Used

- **HTML5:** Semantic and accessible markup architecture.
- **CSS3:** Custom styling with modern layout techniques and dark mode support.
- **JavaScript (ES6+):** Vanilla DOM manipulation, asynchronous network requests, and event handling.
